# Research Quality Checklist

## Source Quantity
- [ ] Quick mode: ≥ 2 sources
- [ ] Standard mode: ≥ 5 sources
- [ ] Deep mode: ≥ 10 sources

## Timeliness
- [ ] 实时需求: Sources < 7 days old
- [ ] 近期需求: Sources < 30 days old
- [ ] 历史需求: No age restriction

## Relevance
- [ ] All sources directly related to topic
- [ ] No off-topic content
- [ ] Covers key aspects of the question

## Traceability
- [ ] All sources have URLs
- [ ] URLs are accessible
- [ ] Sources are credible

## Format Compliance
- [ ] Output matches requested format
  - 摘要: Bullet points + key sources
  - 完整报告: Structured sections + analysis
  - 对比表格: Table format with comparisons
  - 原始数据: JSON/CSV with structured data

## Quality Indicators
- [ ] Information is accurate
- [ ] No hallucinations
- [ ] Multiple perspectives included (for Deep mode)
- [ ] Key findings clearly highlighted

---

## Scoring

**9-10: Excellent**
- All requirements met
- High-quality, relevant sources
- Perfect format compliance
- Deep insights

**7-8: Good**
- Most requirements met
- Quality sources
- Minor format issues
- Good coverage

**5-6: Acceptable**
- Minimum requirements met
- Some relevance issues
- Format mostly correct
- Basic coverage

**<5: Needs Improvement**
- Insufficient sources
- Relevance problems
- Format mismatch
- Missing key information

---

## Severity Levels

**error** (必须修复)
- Insufficient sources
- Off-topic content
- Wrong format
- Broken URLs

**warning** (建议修复)
- Suboptimal source quality
- Minor format issues
- Could be more comprehensive

**info** (可选改进)
- Could add more sources
- Better organization
- Enhanced analysis
